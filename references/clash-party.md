# Clash Party：从运行配置构建独立探针

适用证据：2026-10-19，macOS arm64，Clash Party 1.9.5，自带 Mihomo v1.19.24。路径和行为来自这份本机安装的检查，不代表所有版本。

## 发现入口

该版本 bundle ID 为 party.mihomo.app，但配置仍放在 `~/Library/Application Support/mihomo-party/`。不要由产品名直接推导配置目录。

- `config.yaml`：App 设置，如所选内核。
- `mihomo.yaml`：内核覆盖设置。
- `work/config.yaml`：合并生成的运行配置快照，包含展开的节点。
- App 的 `Contents/Resources/sidecar/`：mihomo、mihomo-alpha、mihomo-smart。

读取 App 设置确认实际内核；`-v`、`-h` 核对当前二进制。快照需检查更新时间与实际使用的订阅；读取成功不保证订阅已经更新。该安装的标准内核支持 `-d <临时目录> -f <配置>`，不需要 TNT 的 IPC。

## 本次开发暴露的问题

1. 配置的模式为 direct，且 TUN 开启。不能整份复制后仅换端口。测试配置应使用专用 select 组和 `MATCH,<测试组>`，并关闭 TUN 和不需要的监听。
2. 展开的 proxies 包含流量、到期、重置信息条目，它们也有合法代理类型。候选数应单列元信息过滤；过滤规则允许调整，不代表这些条目在所有订阅中都存在。
3. 此实例没有 proxy-providers。只支持展开节点的适配器应拒绝未知 provider/链式/文件依赖，而不是跳过后报告“全量”。
4. 沙箱内执行内核和读取默认路由曾被系统拒绝；在已授权的沙箱外执行成功。这属于执行环境限制，不是节点失败。保留报错上下文，不把放宽全部权限写成通用安装步骤。
5. agy 启动时出现登录要求，同时已有遥测和更新流量经过代理。登录等待被早期实现误判为超时，遥测主机被早期实现误当推理主机。最终实现分别检测登录提示、CLI 路径和确切推理服务主机；没有完整推理时不宣布端到端成功。

6. 完成登录后的现场请求使用 `daily-cloudcode-pa.googleapis.com`，与最初默认核对的 `cloudcode-pa.googleapis.com` 不同。将新主机作为确切服务域名加入适配，而不是放宽为整个域名后缀。首个日本节点的请求获得明确地区拒绝，连接链与目标节点一致；失败响应也可验证请求路径，但不能证明模型可用。

## 构建方式

从解析后的节点数据生成最小配置：随机 select 组、rule 模式、MATCH 规则；动态回环混合端口与控制端口、随机 secret、allow-lan=false、bind-address=127.0.0.1；其他端口关闭，TUN/DNS 监听关闭，缓存持久化关闭。若节点依赖本地文件或其他代理，先实现依赖复制与验证。

以发现的物理网卡设置 interface-name。启动后使用带 secret 的 API 检查版本及唯一测试组的成员，确认专用策略生效。不要读取或控制现有 App 的控制端口。

为每个节点启动新 CLI 进程，监测独立内核的 `/connections`：关联 CLI 可执行文件、目标服务主机与 chains 中的节点。只有遥测连接时记录“CLI 走代理，推理路径未验证”。快速结束的连接可能被轮询漏掉，可改用日志或其他关联证据；漏采应判未验证。

HTTP 请求的 EOF 是传输失败：即使错误前缀叫 Eligibility check failed，也不能据此认定用户账号不具备资格。保留精确错误阶段，再分类。

## 已执行验证及边界

真实内核启动、候选枚举、真实 CLI 流量路径、登录提示处理，以及正常结束/启动失败/超时/中断的清理均有本机检查。完成登录后抽样 7 个不同节点：5 个服务地区拒绝、1 个超时、1 个 HTTP 资格检查请求发生 EOF，0 个成功回复。6 个样本采集到推理主机与目标节点的连接链，EOF 样本没有。模拟 CLI 只用于判定与生命周期测试；真实成功回复路径仍缺正例。此结果不证明客户端整体不可用，也不是账号与出口 IP 谁造成拒绝的因果诊断。

当前参考适配器针对标准 Mihomo 与已展开节点；Windows、Linux、provider、smart/alpha 内核、直接控制 App、持久应用最优节点没有因此得到兼容性证明。

官方参考（实现时重新核对）：[Mihomo 全局配置](https://wiki.metacubex.one/config/general/)；[控制 API](https://wiki.metacubex.one/api/)。本机发现优先于对版本的猜测。
